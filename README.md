# HTML Task 2: LaundryWallah Page

This is a simple "LaundryWallah Landing page" HTML project.

## How to Run

To view the webpage, you can simply open the `index.html` file in any web browser.

### Method 1: Using File Explorer

1. Navigate to the `Html-task2` folder on your computer.
2. Double-click on the `index.html` file. It should automatically open in your default web browser.

### Method 2: Drag and Drop

1. Open your preferred web browser (e.g., Chrome, Firefox, Safari).
2. Drag the `index.html` file from your file explorer and drop it into the browser window.

### Method 3: From the Browser

1. Open your web browser.
2. Press `Ctrl + O` (Windows/Linux) or `Cmd + O` (Mac) to open a local file.
3. Browse to the `Htmltask1` directory and select `index.html`.

### Method 4: Using VS Code (Live Server)

If you are using Visual Studio Code:

1. Install the "Live Server" extension.
2. Open the project folder in VS Code.
3. Right-click on the `index.html` file in the explorer panel and select **"Open with Live Server"**.
